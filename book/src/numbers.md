# Numbers

An integer is written as is: `20`, `-3`.

A floating-point number is written as is too. One equal to an integer is written without its fractional part. Not-a-number and the infinities are written `NaN`, `inf` and `-inf`.

```json
{"count":20,"price":1.5,"weight":1.0}
```

```mison
count=20 price=1.5 weight=1
```

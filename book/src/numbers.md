# Numbers

An integer is written as is: `20`, `-3`.

A floating-point number is written as is too. One equal to an integer is written without a fraction: `1`, not `1.0`. Not-a-number and the infinities are written `NaN`, `inf` and `-inf`.

```json
{"price":1.5,"weight":1.0,"delta":-3}
```

```mison
price=1.5 weight=1 delta=-3
```

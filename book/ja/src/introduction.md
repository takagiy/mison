# はじめに

## 概要

MISON（minimal and simple object notation）は、人が読みやすく、そのため言語モデルにとっても解釈しやすい、JSON に似た構造化データの記法です。

```json
[{"ok":true,"file":"a.rs","range":[[2,2]]}]
```

```mison
ok=true file=a.rs range=2-2
```

## 用途

主な用途は、構造化データを少ないトークン数で言語モデルに渡すことです。

RPC や API のリクエストとレスポンスのように、言語モデルを介さないプログラム同士のやりとりは想定していません。

## 型とパース

MISON をパースするプログラムは、期待するデータの型をすでに知っています。そこで MISON は、型から補える引用符や括弧を書かず、同じデータを JSON より短く書きます。たとえば `age=20` は、型が数値なら 20、文字列なら `"20"` と読みます。

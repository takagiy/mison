# はじめに

MISON（minimal and simple object notation）は、JSON に似た、トークン効率がよく人にも読みやすい記法です。JSON が書くデータを、より少ない文字数で書きます。ツールの出力を読む言語モデルのように、読む文字数そのものにコストがかかる読み手のための記法です。

```json
[{"ok":true,"file":"a.rs","replaced":[[2,2]]}]
```

```mison
ok=true file=a.rs replaced=2-2
```

MISON は、読み手が推し量れるものを書かないことで短くなります。ふつうの文字列を囲む引用符、レコードを囲む波括弧、キーの後ろのコロン、そして値を 1 つしか持たないネストです。

その代わり、MISON のテキストは値ごとの型を示しません。`age=20` は数値の 20 かもしれず、文字列の `"20"` かもしれません。MISON を読むプログラムは、期待するデータの形をすでに知っていて、その形から各値の読み方を決めます。型による読み方は、[形式的定義](semantics/syntax.md)で厳密に定めます。

値の各章では、同じデータを JSON と MISON で並べて示します。

# 文字列

文字列は、テキストを表す文字の並びです。そのまま書きます。

```json
"alice@example.com"
```

```mison
alice@example.com
```

空の文字列は `""` と書きます。

```json
""
```

```mison
""
```

## 引用符で囲む文字列

特別な文字を含む文字列は、二重引用符で囲みます。

```json
"Hello, World"
```

```mison
"Hello, World"
```

特別な文字は次のとおりです。

| 文字 | 引用符の外での意味 |
|---|---|
| 空白（スペース、タブ、改行など） | フィールドや行を区切る |
| `=` | キーと値を区切る |
| `,` `;` | 配列の要素を区切る |
| `(` `)` | ネストした値をまとめる |
| `"` | 引用符で囲む文字列を始める |
| `[` `]` | 5 次元以上の配列を囲む |

`[` と `]` は、[5 次元以上の配列](arrays.md#5-次元以上の配列)の中でだけ特別な文字です。

## エスケープ

引用符の中では、`"` を `\"`、`\` を `\\` と書きます。

```json
"say \"hi\""
```

```mison
"say \"hi\""
```

改行はエスケープする必要がありません。

```json
"Hello\nWorld"
```

```mison
"Hello
World"
```
